# 2026-08-05 네이버 자동 재인증

## 배경

네이버 세션 만료 때마다 사람이 로그인할 때까지 전체 생성·발행이 멈추고, 중단 기간에도 일일 레코드가 만들어져 대기열이 증가했다.

## 변경

- macOS Security Framework 기반 Keychain 저장·조회·삭제 모듈 추가.
- 비밀번호가 `.env`, SQLite, Git, 로그, 프로세스 명령행에 남지 않도록 구현.
- 키체인 자격증명이 있으면 세션 만료 시 백그라운드 자동 로그인 시도.
- CAPTCHA·2단계 인증·계정 보호 화면은 감지 후 수동 확인으로 전환.
- 실제 자동 로그인에서 네이버의 `보안을 위해 추가 확인` 응답을 확인하고 반복 시도를 중단하도록 분류.
- 수동 로그인 창은 Keychain 자격증명을 자동 입력해 사용자가 보안 확인만 완료하도록 개선.
- 자동 로그인 성공 시 `naver_state.json` 갱신 및 계정 자동 활성화.
- 재로그인 대기 중 신규 글 레코드 생성과 기존 대기 글 처리 모두 중지.
- 과거 8월 2~4일 대기 30건은 보존 취소하고 오늘·내일 20건만 유지.

## 일회성 설정

`../venv/bin/python -B setup_naver_credentials.py --gui`

macOS 보안 입력 창에서 아이디와 비밀번호를 한 번 입력하면 키체인 저장 후 즉시 자동 로그인 검증을 수행한다. 비밀번호 입력값은 화면에 표시되지 않는다.

## 검증

- 임시 자격증명으로 실제 Keychain 저장·조회·삭제 왕복 성공.
- 자동 인증, GUI 숨김 입력 및 기존 복구 테스트 9개 통과.
- 전체 Python AST 검사 통과.
