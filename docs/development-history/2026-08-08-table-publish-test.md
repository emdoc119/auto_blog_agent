# 2026-08-08 네이버 표 발행 실험

## 변경

- SmartEditor가 클립보드 HTML 표를 평문으로 내리는 것을 확인.
- Markdown 표를 모바일용 텍스트 카드(`📌 항목`, `- 헤더: 값`)로 정규화.
- 행 사이 빈 줄이 있는 표도 인식하도록 파서를 보강.
- `tests/test_auto_post_formatting.py`로 회귀 테스트 추가.

## 실전 검증

- 384번과 390번은 이전 HTML 방식으로 발행되어 원시 표가 남음.
- 최종 수정 후 385번 `관절 통증에 마음까지 지치셨나요? 과학이 증명해 드립니다`를 시험 발행.
- DB 상태 `published`, RSS 제목 확인.
- 실제 게시 페이지에서 `|---|` 및 `| 구분 |`이 사라지고 카드형 `📌` 텍스트가 표시됨.
- 전체 테스트 26개 통과.

## 결론

- 네이버 자동 발행에서는 시각적 HTML 표보다 평문 카드가 재현성과 모바일 가독성이 높음.
- 이미 발행된 384/390번은 자동 수정하지 않으며, 이후 발행 글부터 새 형식을 사용.
